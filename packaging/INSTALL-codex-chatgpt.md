# Install - AI Prompting (Codex / ChatGPT plugin)

**Not for the Claude app skill uploader.** For a personal standalone skill in ChatGPT desktop, Codex CLI or the IDE extension, the `…-UNIVERSAL-skill.zip` is simpler.

For local development: extract this ZIP, add its outer `ai-prompting/` folder to a local plugin marketplace, install it, refresh the app and test in a new conversation. Publication to OpenAI's plugin directory is a separate OpenAI review step and is not claimed here.

Smoke test: ask for a short Opal pointer prompt. A loaded skill reports **Loaded AI Prompting v1.0.8**.
